Designing Badges and Overlays

Badges and overlays add status indications or secondary contexts to your main icon design without cluttering the primary symbol.

With Icon Studio's Badge controls, you can overlay secondary indicators in a way that remains clean and legible at small sizes. Proper design practices ensure these status badges do not compromise the visual hierarchy of your core design.

Hierarchy & Positioning

A badge should always act as a secondary indicator. In Icon Studio, you can place badges using the Badge Position controls under the Badge tab:

  • Top L / Top R (Top Left / Top Right): Best for status alerts, counts, or notification symbols.
  • Bottom L / Bottom R (Bottom Left / Bottom Right): Typically used for action badges or user indicators. Bottom R is the default position.
  • None: Removes the badge entirely to focus solely on the primary canvas graphic.

Ensure that the primary icon is aligned away from the badge's position. For example, if a badge is set to the bottom right, keep the base design elements toward the top left to keep the overall layout balanced.

Scaling Ratios

Correct sizing proportions prevent a badge from either overwhelming the core design or becoming unreadable.

  • Badge Size: Controls the size of the badge container relative to the main canvas.
    • Default (40%): The ideal balance for standard logos.
    • Range (20% - 60%): Adjust lower (20%-30%) for clean, subtle additions, or higher (50%-60%) if the badge icon itself requires high readability.
  • Badge Icon Scale: Adjusts the scale of the symbol inside the badge.
    • Default (70%): Standard proportions.
    • Range (20% - 100%): Adjust lower to increase the negative space (clearance) around the symbol.
  • Badge Rotation: Rotates the badge container and icon from 0° (default) to 360°. Useful for diamonds or directional arrow indicators.

Contrast and Clearances

To make a badge pop against your background, it must have clear isolation and sufficient contrast.

Badge Shapes

Select a shape from the Badge Shape selector to match your design system:

  • Circle: Provides the softest transition, isolating the badge neatly on most backgrounds.
  • RoundRect / Squircle: Complements app designs that use rounded base shapes.
  • Square: Delivers sharp, geometric contrast.
  • Hex V / Hex H: Vertical and horizontal hexagons provide a stylized tech look.
  • Diamond / Shield: Excellent for security, gaming, or rating badges.

Smart Contrast & Isolation

To guarantee readable overlays, Icon Studio features an automated high-contrast rendering engine:

  1. Clearance Borders: A built-in border surrounds the badge container to separate it from the underlying base gradients and effects.
  2. Auto Contrast: The badge icon dynamically adjusts its contrast matching standard accessibility requirements, keeping the design legible even when exported at high resolution.
