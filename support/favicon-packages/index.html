Creating Multi-Resolution Favicon Packages

A single icon file is no longer sufficient to support all web browsers, operating systems, and device shortcuts. Learn how to assemble a complete, modern favicon package using HTML and PNG.

By exporting your custom design at high resolution from Icon Studio, you can downscale and pack your asset into the precise formats needed for desktop tabs, mobile shortcuts, bookmarks, and Progressive Web App (PWA) configurations.

The Modern Web Standard

Traditionally, websites relied on a single `.ico` file located in the root directory. Today, browsers run on high-density screens (Retina, Super Retina), mobile OS environments (iOS/Android), and standalone PWA displays, requiring different icon resolutions.

The modern approach uses highly compressed, transparent PNG files linked explicitly via HTML headers. This ensures:

  • Crisp Rendering: Pixels map perfectly to high-DPI displays.
  • Performance: Browsers only download the specific size they need.
  • Integration: Devices can fetch branding symbols for home-screen bookmarks and system taskbars.

Target Sizes Checklist

When exporting your final design from Icon Studio, resize the 1024x1024 PNG output to populate this standard suite of assets:

File Name Size (Pixels) Use Case
favicon-16x16.png 16 × 16 Classic browser tabs and address bars.
favicon-32x32.png 32 × 32 Desktop shortcuts and tab listings.
apple-touch-icon.png 180 × 180 iOS and iPadOS Home Screen bookmark icons.
web-app-manifest-192x192.png 192 × 192 PWA installation drawer and launcher shortcuts.
web-app-manifest-512x512.png 512 × 512 PWA splash screen and Android setup headers.

Assembly & Manifests

Once your image files are ready, integrate them into your web page and link a configuration manifest.

HTML Header Snippet

Add the following tags to the <head> section of your HTML document: 

<!-- Standard Tab Favicons -->
<link rel="icon" type="image/png" href="/assets/favicon/favicon-16x16.png" sizes="16x16" />
<link rel="icon" type="image/png" href="/assets/favicon/favicon-32x32.png" sizes="32x32" />

<!-- iOS / Apple Devices -->
<link rel="apple-touch-icon" sizes="180x180" href="/assets/favicon/apple-touch-icon.png" />
<meta name="apple-mobile-web-app-title" content="Your App Name" />

<!-- Web App Manifest Link -->
<link rel="manifest" href="/assets/favicon/site.webmanifest" />

Structure of site.webmanifest

Create a text file named site.webmanifest (or manifest.json) in your favicon folder and define your application identity and icon references: 

{
  "name": "Your Web Application Name",
  "short_name": "App Name",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#020617",
  "theme_color": "#020617",
  "icons": [
    {
      "src": "/assets/favicon/web-app-manifest-192x192.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "any"
    },
    {
      "src": "/assets/favicon/web-app-manifest-512x512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any"
    }
  ]
}
