Designing for Light and Dark Themes

Modern user interfaces toggle between light and dark backgrounds and achieving sufficient contrast can be challenging. This guide outlines contrast requirements, border configurations, and dynamic markup methods to ensure icons remain visible on any background.

Contrast Matters

Transparent icons without background shapes can disappear when placed on backgrounds of a similar color.

  • Matching Colors: A dark-colored icon disappears on a dark interface. A light-colored icon disappears on a light interface.
  • Accessibility Guidelines: Graphic elements should maintain a minimum contrast ratio of 3:1 against their backgrounds to be readable.

Compare the contrast outcomes across typical theme backgrounds:

Icon Type Light Background (#FFFFFF) Dark Background (#121212) Strategy
Pure White SVG/PNG Invisible (1:1 contrast) Visible (21:1 contrast) Needs dark-theme design or background container
Pure Black SVG/PNG Visible (21:1 contrast) Invisible (1:1 contrast) Needs light-theme design or background container
Transparent + Container Visible (> 4.5:1 contrast) Visible (> 4.5:1 contrast) Works on both themes

Visual Boundaries

To guarantee visibility on varying canvas conditions, use one of the following geometric boundaries.

1. High-Contrast Borders

Apply an explicit border surrounding the icon symbol to isolate it from the underlying interface background:

  • Border Width: Use a thickness between 1px and 2px.
  • Border Color: Use a color opposite to the primary icon content, or a high-contrast neutral color. For example, add a 1.5px solid white (#FFFFFF) border to dark symbols.

2. Neutral Backing Containers

Embed the icon symbol inside a solid or semi-transparent background shape. This creates a predictable local contrast area regardless of the platform theme:

  • Opacity Range: Set the background color container between 8% and 15% opacity (for example, rgba(0, 0, 0, 0.1) for light backgrounds, or rgba(255, 255, 255, 0.1) for dark backgrounds).
  • Corner Curvature: Use a squircle or circle container to align with standard platform masks.

Dual-Variant Implementation

The standard method to dynamically load matching assets based on system color schemes is the HTML <picture> element.

By matching media queries against the user's system preferences, the browser fetches and displays the correct asset variant without executing JavaScript. 

<picture>
  <!-- Loaded when system dark mode is active -->
  <source srcset="icon-home-32px-dark.png" media="(prefers-color-scheme: dark)">
  
  <!-- Fallback loaded on light mode or unsupported browsers -->
  <img src="icon-home-32px-light.png" alt="Home Icon" width="32" height="32">
</picture>

This implementation requires two distinct exported graphics:

  1. icon-home-32px-dark.png: Configured with light colors for dark interfaces.
  2. icon-home-32px-light.png: Configured with dark colors for light interfaces.
